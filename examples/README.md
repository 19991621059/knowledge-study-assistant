# 示例资料

`backup-study.json` 是完整的 `study-bundle-v1` 原创资料包，包含5段文字和3道手写示例题；页面“导入示例”使用这个文件。`backup-study.md` 是同一正文的Markdown版本，用于体验文件上传和根据资料生成题目。

这两份资料由本项目原创，按根目录MIT许可证公开，不是口腔教材或考试真题，不包含原项目教材、原题库或图片。用户自己的资料只保存在其自部署服务中，导入不自动授予公开分发权。

JSON格式：根对象包含`format: "study-bundle-v1"`、`title`、`pages: [{text: "原文"}]`以及可选的`questions`。题目包含`stem`、2至6个`options`、从0开始的`answer`索引数组、`explanation`及`sources: [{page: 1, quote: "至少8字的逐字原文"}]`。`page`表示资料包中的原文段号，PDF则使用物理页码。

整份资料先校验，任意题目格式、答案索引或逐字出处不合法时，整份导入失败，不保存半份题库。没有题目时可以先阅读，再在“练习复习”中生成AI参考题。
